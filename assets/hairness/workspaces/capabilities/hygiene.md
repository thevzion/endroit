# Inspect Workspace hygiene

Run `workspace doctor` before proposing repairs.

Separate confirmed inconsistencies, ownership ambiguities, legacy residue and
optional improvements. Check required documents, scoped owner references,
duplicate IDs, broken lifecycle links and Asset namespace collisions.

Inspection is read-only. Never move, archive, delete, promote or rewrite
material without an explicit bounded request. A disorderly Workspace is
recoverable because its owner and contracts remain inspectable.

Configure the smallest useful Home and Desk through conversation.

1. Read the HUD and distinguish shared Home settings from personal Desk
   settings.
2. In a team Home, offer three explicit paths: create a private Desk, clone an
   existing private Desk repository, or continue temporarily without one.
   Never place a machine path in `desk.json`.
3. Ask how the user wants to be addressed and which response language to use.
4. Discover setup contributions from installed Assets and propose only the
   relevant ones.
5. Present exact changes and wait for consent before calling the CLI.
6. Build and run Doctor after accepted changes.
7. Explain that Scratch is optional and install it only after consent.

Do not create an onboarding journal, transcript or implicit memory.

Create an inspectable Target Map without modifying the Target.

1. Select a declared Target and a concrete Binding.
2. Use `hairness target map <target> [--binding <binding>]`.
3. Treat the generated map as bounded evidence, not inferred business truth.
4. Review uncertainties and secret-scan results before publishing the Artifact.
5. Publish to the Home only when the map should become shared knowledge.

The deterministic Kernel mapper reads tracked paths, Git evidence and declared
package metadata. Deeper interpretation remains a collaborative agent task.

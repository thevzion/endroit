# Federation fixture

Three synthetic sovereign Workplaces qualify Link, local Attachment/Binding,
derived Registry, exact Mount resolution and separate target Front Doors.

`anchor/world/bindings/` contains versioned local-state templates. Tests copy
the worlds to an OS temp directory and materialize those templates under the
ignored `.endroit/` paths before running `ready`. No real Workplace, remote,
credential or private organization data belongs here.

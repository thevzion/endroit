# Changelog

## 0.1.0-rc.1 — 2026-08-27

First source-only Static Workplace release candidate. Human qualification and
cross-model convergence remain open; this release does not claim acceptance.

### Added

- `endroit new` interactive wizard powered by `@clack/prompts@1.7.0`.
- Digest-bound JSON Preview/Apply for fresh personal Workplaces.
- Atomic creation of separate shared and private Desk Git Roots on `develop`.
- Hall-local `open-room` progressive affordance.
- Static Workplace compilation from strict YAML sources and closed JSON.
- Mounted Front Doors with bound Member, Desk, WELCOME and source revisions.
- Semantic disclosure selectors, Disclosure Contracts and progressive links.
- ProviderBinding allowlists and Desk-owned Memory Policy routing.
- `.workplaceignore` discovery policy and deterministic freshness.
- Static brownfield Workplace Preview with no implicit Apply.
- Generic local Work/Site path with explicit delivery exclusion.
- Owned CoordinationPolicy, normalized IR and progressive Manager/Worker contracts.
- Meeting as the sixth durable Standard family, with local presence and Occupants.
- Public staged/history Git witness and consented Shared/Desk commit hooks.
- Bounded settle planning and immutable qualification run directories.
- Smallest, rich, FieldLab and Flappy examples and Path/Outcome qualification.
- Closed Workplace Profile Package with explicit Grammar, Lexicon,
  responsibilities, defaults and situated fundamental affordances.
- Definition/Lexicon IR, ControlClauses and per-method Context Contracts.
- Fail-closed Meeting/dispatch proof for multi-Root Work.
- Append-only qualification snapshots and explicit terminal verdicts.
- Explicit dev-only Codex Scenario replay with sanitized read, Skill, dispatch
  and effect evidence.

### Changed

- Compile explicit bounded Constitution, Doctrine and CHANGE resident clauses
  before Hall routing; keep provenance in IR/comments and remove visible
  provider-adapter boilerplate.
- Local provider surfaces are materialized at the provider-opened Mount while
  portable control-plane files remain in the Shared Root.
- Staged Git guards load the same local ProviderBindings as Mount checks.
- The official Bun test gate excludes ignored qualification Mounts.

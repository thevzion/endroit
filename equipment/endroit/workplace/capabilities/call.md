# Call the researcher

Use the current provider's native subagent mechanism to call one temporary
researcher Occupant with the current Binding, authorized sources, constraints
and expected result. Codex and Claude have first-party, statically qualified
projections; runtime delegation still depends on the active provider host.

If the provider cannot delegate, return `blocked` and name the missing provider
capability. Never simulate a spawn, invent a persistent agent registry or turn
the Occupant into a Member.

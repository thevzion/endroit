# Advance the work

Consume the current actionable result or accepted plan. Normal conversation
such as “implement this plan” is sufficient to activate the same behavior;
`advance-this` is an optional explicit accessor.

Resolve the owning Room, affected Sites, selected Routes and responsibility
boundaries before mutation. Revalidate every Route immediately before its
mutation and keep each Site's source, history, permissions and delivery
lifecycle sovereign.

Delegate only independent Site or responsibility boundaries through the
provider's native subagent mechanism. Give every delegate the current Binding,
actionable object, approved scope, constraints and approval limits. Delegation
never adds authority. When native delegation is unavailable, work
sequentially; never simulate subagents or add an orchestration runtime.

Integrate the bounded results, run the relevant checks and report observed
evidence. Do not create continuity for work that can finish in this Meeting.
For multi-Site or multi-session work, compose `endroit/planning` only when it
is installed and the human authorized durable planning. Otherwise ask before
installing it or leave the result ephemeral.

Never infer retain, accept, archive, deliver, commit, push, publication or
deployment from the request to advance the work.

# Manage a Release

Use Site-owned `public-surface` Artifacts and one Workplace-owned `release`
Artifact to assemble a deterministic local release plan. Resolve every Site
through an explicit active Route, keep source intent free of Git and host
details, and write volatile evidence only to the lock or receipt.

`preview`, `lock`, `verify` and `watch` do not push, merge, publish or deploy.
`observe` records an effect already observed through another authorized
system; it never performs that effect.

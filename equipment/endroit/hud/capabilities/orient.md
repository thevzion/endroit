# Orient in the Workplace

Start with the generated provider bootstrap. It contains the Workplace
identity, Constitution and tracked Console, not a live inventory. Add the live
HUD only when the current request depends on local state.

The Wake-up carries no detailed Room, Site or Capability inventory. Prefer an
explicit human selection, inspect only the corresponding owned source,
continue a unique semantic match and ask one short question when the match is
ambiguous.

Treat the overlay as a local snapshot. Refresh it once when relevant state may
have changed, surface blocking attention before acting and revalidate a Site
immediately before mutating it. If the HUD is unavailable, continue from the
bootstrap. Use `room list`, `site list` and `equipment catalog` as targeted
read-only inspections, and report the degraded orientation instead of
searching outside the Workplace for a replacement.

When recent change matters, use the HUD Activity view. Treat Endroit metadata
as authoritative and Git or filesystem evidence as observed. Activity is a
computed view, not a durable journal, and cannot prove an unobserved cause.

# Planning Initiative

Create or resume one bounded operational outcome after resolving its owning
Room and Meeting.

Use one `endroit/planning:initiative` Artifact. A request to implement moves it
to `active`; Planning adds no approval gate. Create an Initiative only for
durable multi-step work, material arbitration, substantial verification or
likely resumption.

The Artifact owns current operational intent. Git owns technical history and
Decision Documents own accepted decisions. Announce each created Initiative.

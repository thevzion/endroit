# Endroit

## Engineer predictable paths from intent to outcome

Agent reasoning is powerful because it is not a script. That also makes a flat
prompt a weak place to carry ownership, evidence, destinations and Authority.

Endroit lets you design the environment around the reasoning:

```text
Intent
→ Place
→ Meeting
→ Work
→ Workshop
→ required sources and decisions
→ sovereign Site
→ compounded Outcome
```

The compiler is deterministic. The Agent remains probabilistic. The semantic
Path around its reasoning becomes visible, correctable and qualifiable.

> **Design the path, not the prompt.**

## Start with an empty building

```sh
endroit new ~/Workplaces/studio
```

Endroit introduces the Workplace, asks for its human Member and private Desk,
shows the exact files and commits, then creates only what was approved. The
result starts with a Hall, a Member Card, a bounded WELCOME packet and one local
`open-room` affordance—not a demo project disguised as your workspace.

Open the printed folder in Codex or Claude. A new intention can then discover
its own Room, Meeting, Work and sovereign Site progressively.

## Adopt before you mutate

Point Endroit at an explicitly authorized environment. It can produce a sourced
Workplace Preview: observations, inferences, unknowns, exclusions, proposed
Places, owners, Sites and exact effects.

The Preview grants no mutation authority. Correct it, stop with the map, or
consent to an exact Apply. Existing repositories remain sovereign Sites.

## The Flappy test

Give a capable Agent the same high-level intent twice:

> Build a Flappy Bird game with a twist.

Without a Workplace, the likely Outcome is a game.

With Endroit, the Agent can enter the relevant Room, discover a local Study,
read existing evidence, resolve Work, build only in the declared Site, verify
it and leave durable provenance for the next intention.

## A building, not a context dump

The Hall shows Places and the situated Meeting. A Room shows local Meetings,
Work and Workshops. A Work surface
shows determining sources, verification and its Site. The Site surface links
its own contract and checkout.

> Compile globally. Disclose locally. Load on intent. Execute with proof.

A constraint that governs an effect lives on the shortest valid path to that
effect: resident before routing, required when a method becomes applicable, or
guarded when truth would otherwise become durable. Multi-Root Work cannot
quietly collapse into one Agent doing everything.

Installed does not mean visible. Visible does not mean applicable. Executable
does not mean authorized.

Coordination is part of the building: Main stays with the human, a Manager
appears only when Work needs integration, and a Worker receives one bounded
Workbench or Site scope. The Workplace owns that policy; provider capabilities
only execute it.

Durable changes carry a Git witness. Local hooks catch invalid staged sources
and commit trailers before the commit; the same public check audits history, so
`--no-verify` cannot turn a dangling Meeting into qualified truth.

## Static first

Endroit compiles Front Doors, maps, manifests and provider adapters to ordinary
files. The building remains navigable without Bun, the compiler or a daemon.

# Doctrine

## Resident

- Resolve an existing owner, Place and Work before proposing creation.
- Load the smallest sufficient context through local Front Door links.
- Expose assumptions that can change direction before dependent effects.
- Ambiguous destination, ownership, visibility or Authority means one question and zero writes.
- Installed is not visible; visible is not applicable; applicable is not authorized.
- Prefer one bounded verified Outcome over speculative structure.

# 0.8.0-alpha.0

Endroit 0.8 resets the product around Home-first workplaces.

## Breaking changes

- Workspace becomes Room.
- Asset becomes Equipment.
- Target becomes Site.
- Binding becomes Route.
- Workstream is no longer a public durable container by default; retained
  Meeting records and nested Rooms have explicit responsibilities.
- Site declarations move from `endroit.json` settings to `sites/<site>/SITE.md`.
- Route metadata moves to `.desk/routes/<site>/<route>.json`.
- Managed checkouts live separately under ignored `.desk/sites/` paths.
- Old command names receive no permanent aliases.
- `mode: solo|team` and `--mode` are removed. Homes own Members and Desks
  choose a tracked, separate or deferred Git boundary.

## Added

- `endroit init` for an Embedded Home in an existing Git repository;
- standalone and embedded Home topologies;
- remote-only Sites;
- existing, managed clone, managed worktree, embedded and submodule Route modes;
- first-class Site and Route schemas;
- safe managed checkout deletion with dirty and worktree guards;
- a production Home-first README and 0.7 migration guide.
- Home-owned Member documents and `member create|list|inspect|doctor`;
- required Desk-to-Member references and contextual `create`/`init` defaults;
- literal or `{route}`-templated `projectedName` accessors with collision refusal;
- provider-native entry, call, Role, method and lifecycle gestures;
- bootstrap whole-Home Hygiene with read-only inspection and exact repair approval;
- an npm `next` publication, registry smoke test and separate `latest` promotion.

## Not included

- automated migration;
- submodule lifecycle management;
- semantic placement or implicit hygiene mutation;
- daemon, graph, index or persistent agent.

# Endroit 0.10.0-alpha.0 release candidate

This document describes the local candidate. It becomes release evidence only
after the exact commit, package and public schemas have passed the release
workflow and the registry effect has been observed.

## What changed

- Native `WORKPLACE.md`, Member and Desk v9 declarations.
- Deterministic `ResolvedWorkplace` revisions and compact provider projections.
- Pathless Route v9 declarations with Desk-partitioned Checkout bindings.
- Journaled Route v7→v8→v9 migration with read-only preview and exact rollback.
- `WORK.md` v1alpha2 with typed Fragments and revision-bound completion.
- Public v9 and Work schema inventory included in the release manifest.

## Compatibility

The 0.10 candidate reads frozen v7 declarations and Route v8 through its
compatibility adapter. Earlier unversioned v6 contracts remain frozen public
history, not accepted inputs. The candidate does not include a whole-Workplace
migration. Room, Site and most Equipment and Artifact writers retain their
compatible source shapes. `WORK.json` v1alpha1 remains read-only. See the
[0.9 → 0.10 upgrade guide](../migration-0.10.md) before changing existing data.

## Qualification gates

The exact release commit must pass:

- tests on Node.js 22 and 24;
- source, schema and frozen-contract checks;
- conformance and provider projection parity;
- package-content and packed-lab checks;
- public schema status, media type, CORS, `$id` and SHA-256 verification;
- npm dry-run before any publish effect.

Publication is separate human-authorized work. This note does not claim that
the package, schemas, documentation or website are already public.

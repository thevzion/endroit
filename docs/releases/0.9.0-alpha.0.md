# 0.9.0-alpha.0

Endroit 0.9 introduces the v8 Route contract and an explicitly resolved
Checkout without changing Open Workplace object identity.

- New Route writes use nested `checkout` metadata and explicit
  `active|parked|superseded` lifecycle.
- The Core reads v7 and v8 through one loader; v7 remains frozen.
- `checkout list|inspect|resolve` separates declared metadata from live observation.
- `checkout adopt|clone|worktree|reconcile|delete` owns local materialization
  while Route commands keep only relationship lifecycle.
- Duplicate Git directories are rejected while linked worktrees may share a
  common Git directory.
- Inactive Routes are excluded from operational selection and implicit Site,
  HUD and Artifact routing.
- `route migrate --check` previews a metadata-only cutover; applied runs carry
  exact rollback material without persisting Git observations. An exclusive
  local lock and per-Route journal progress make interrupted apply and rollback
  runs resumable without overwriting drift.
- The manifest-backed physical index distinguishes direct, linked, missing,
  broken, divergent and conflicting states without deleting unknown paths.
- Optional `revision` separates Route identity from branch or commit
  constraints; provider worktrees remain observed until explicitly adopted.

This is a local release candidate. Publication, push and deployment are not
implied.

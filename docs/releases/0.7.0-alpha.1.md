# Endroit 0.7.0-alpha.1

This patch aligns the public grammar and bundled documentation before the
first editorial launch.

## What changed

- Home-first responsibilities are named as Places, Orientation, Capabilities,
  Material and Relationships.
- Endroit maps those responsibilities to its existing Home, Desk, Workspace,
  Asset, Artifact, Target, Binding and Handle contracts.
- The interaction model is structurally explicit and conversational by
  default.
- Publication Artifacts may declare optional responsibility, stability,
  canonical dependency, related reading and update-trigger metadata.
- A published Publication may reopen a draft source revision without changing
  its observed external Handle.
- Remaining live references to Ness were removed from the HUD payload and
  reference documentation.

## What did not change

There is no new CLI command, Agent Runtime, Home topology, Target behavior,
schema version or migration. Existing Publication Artifacts remain valid
because every new field is optional.

## Qualification

The release candidate must pass the Node 22 and Node 24 test matrix, check,
conformance, provider, pack, lab and Development Home gates before any
publication approval.

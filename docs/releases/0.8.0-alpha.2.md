# 0.8.0-alpha.2

> Release candidate. Publication is not implied by this file.

Endroit 0.8.0-alpha.2 is the candidate for the Workplace-first application
framework: build the place where humans and agents work from owned sources,
then resolve it into provider-readable projections and optional operations.

It also introduces experimental Work Resolution: a small, Room-owned contract
that makes objective, authority, claims, obligations, Assignments, evidence
and review inspectable independently of a temporary agent.

## Added

- An explicit public framework boundary across the Open Workplace protocol,
  Endroit Profile, resolved Home, Equipment and provider projections.
- `endroit/work:item` with `artifact.md` and `WORK.json`.
- Public schema `https://endroit.org/schema/work/v1alpha1.json`.
- Runtime commands `work inspect`, `work resolve`, `work review` and
  `work record-review`.
- Generic Publishing Work schemas and `publishing list|inspect|validate` plus
  the reversible, mapping-bounded `editorial-work-v1` migration.
- Provider projections `resolve-work` and `click-and-review`.
- Package-owned `WORKPLACE.md` and `ADOPT.md` projections.

## Boundaries

The framework claim describes the currently implemented file-based Home,
resolver, projections and optional Equipment. It does not claim a daemon,
visual application builder, persistent agent or published `alpha.2` artifact.

Work Resolution is an Endroit extension, not an Open Workplace 0.1
requirement. It ships no graph, daemon, scheduler, agent registry, trust score
or implicit authorization. Review never changes Artifact lifecycle or performs
an external effect.

## Qualification

Publication requires the Node 22/24, check, test, conformance, provider, pack
and Development Home gates plus observation of the exact registry artifact.

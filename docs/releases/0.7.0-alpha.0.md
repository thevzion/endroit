# Endroit 0.7.0-alpha.0

Endroit is the new canonical name of the project previously released as
Hairness.

This alpha is a deliberate breaking cutover. It ships `@endroit/cli`, the
`endroit` binary, `endroit.json`, `endroit.mjs`, `.endroit/`, Endroit Asset
IDs and schema v6 under `https://endroit.org/schema/*`. It does not parse or
alias the former contracts.

Existing repositories remain independent. The cutover changes the owned Home
environment around them, not their source, history or delivery.

No migrator is published. Alpha users should create a fresh Home or perform an
explicit, reviewed local migration before replacing their existing setup.

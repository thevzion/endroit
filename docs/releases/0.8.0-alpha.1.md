# 0.8.0-alpha.1

Endroit 0.8.0-alpha.1 is a focused prerelease correction for brownfield
initialization and npm delivery verification. It does not change schemas,
commands, Equipment contracts or the Workplace model introduced in alpha.0.

## Brownfield initialization

`endroit init` now resolves and checks the complete generated projection set
before its first mutation of an existing repository.

- Existing generated files with identical bytes are accepted.
- Different files, symlinks and non-file entries are reported together as
  `generated_output_collision`.
- A failed preflight leaves the Git working tree and existing files unchanged.
- Endroit still does not move existing instructions, Skills, memory or source
  files during bootstrap.

This closes the partial-initialization failure found during the alpha.0
consent-first brownfield smoke.

## npm delivery

Release verification now distinguishes registry recompression from package
content drift. A bounded in-memory tar reader validates archive checksums,
entry types, duplicate paths and traversal attempts before comparing the
normalized package tree byte for byte.

The registry smoke installs the exact published version into an isolated npm
prefix, verifies the installed package version and declared `endroit` binary,
then invokes that entrypoint directly to create and inspect a fresh Home.

## Upgrade

Use the exact prerelease while it is under qualification:

```bash
npx --yes --package @endroit/cli@0.8.0-alpha.1 endroit create my-home
npx --yes --package @endroit/cli@0.8.0-alpha.1 endroit init .
```

The 0.7 to 0.8 migration remains documented in
[migration-0.8.md](../migration-0.8.md).

# Memory policy

Endroit does not treat provider memory as Workplace truth.

The Constitution owns shared continuity and privacy invariants. A Desk-owned
`MEMORY.md` source owns personal durable routing policy. The bound Hall renders
its summary and link. It does not inline private Desk history.

WELCOME owns resident interaction defaults. Desk sources own personal durable
continuity across providers. Work and Material own reusable outcomes; Meeting
and Workbench state remains current context. Secrets stay outside all of these
surfaces.

A provider-facing `MEMORY.md` is optional. It is emitted only when a qualified
ProviderBinding explicitly selects that path, begins with a generated warning
and routes durable information to Desk, Room, Work/Meeting or Site owners.
Provider cache, transcript, hidden reasoning and credentials remain disposable
or forbidden and are never imported.

# Controls on the effect path

Endroit does not expect an Agent to discover a critical rule voluntarily. A
ControlClause is placed where it can change the next consequential choice:

- `Resident`: visible before routing;
- `RequiredRead`: loaded when the method becomes applicable;
- `MayRead`: optional evidence with a stated reason;
- `Guard`: checked before truth becomes durable.

The compiled Context Contract binds those clauses to a Position, search Root,
forbidden scopes, coordination route, stop condition and proof. Integration
requires a situated Meeting, Manager and bounded Worker dispatches. Missing
proof is RED; provider memory or a global Skill cannot substitute for it.

This is an inspectable behavioral contract, not filesystem isolation. Live
qualification records actual reads, Skills and effects so a path can be
falsified without retaining a transcript or hidden reasoning.

# Concepts

Endroit is an environment for intentional conversation, not a context database.
The human states full intent; the Workplace makes that intent situated without
silently taking ownership of judgment, acceptance or authority.

The durable loop is:

```text
intent
→ situated interpretation
→ determining assumptions made inspectable
→ discussion or bounded action
→ explicit retention when useful
→ a better Workplace
```

Only assumptions capable of changing direction, destination, authority or
Outcome need pre-effect visibility. No hidden model state becomes Workplace
truth.

Git is the required temporal truth. Owned sources are current semantic truth.
Generated Front Doors, maps, registers and ledgers are projections.

Coordination is also owned. A strict policy selects structural Main, Manager
and Worker routes; provider bindings only translate them to available native
capabilities. Neither a role nor a Skill grants Authority.
